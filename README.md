## Реализация алгоритмов классификации отзывов на фильмы по тональности

В данной работе представлено сравнение 3-х моделей классификации Multinomial Naive Bayes, Logistic Regression, Linear Support Vector Classification

Для решения задачи классификации отзывов по тональности применяются классические алгоритмы машинного обучения. После преобразования текста в числовой вид с помощью Bag-of-Words или TF-IDF каждый отзыв представляется вектором признаков, который передаётся на вход классификатору.

датасет был взят по ссылке: https://www.kaggle.com/datasets/lakshmi25npathi/imdb-dataset-of-50k-movie-reviews?resource=download
