# Классификация отзывов на фильмы по тональности

Проект посвящён решению задачи бинарной классификации отзывов на фильмы: положительный или отрицательный отзыв.

В работе сравниваются три классические модели машинного обучения:

- Multinomial Naive Bayes
- Logistic Regression
- Linear Support Vector Classification

Текстовые данные преобразуются в числовые признаки с помощью Bag-of-Words и TF-IDF. После этого обученные модели сравниваются по метрикам качества.

## Данные

Используется датасет IMDb 50K Movie Reviews Dataset с Kaggle:  
https://www.kaggle.com/datasets/lakshmi25npathi/imdb-dataset-of-50k-movie-reviews

## Используемые технологии

- Python
- pandas
- scikit-learn
- Jupyter Notebook
- Bag-of-Words
- TF-IDF
